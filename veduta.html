Bleed and margin

Margin holds the map off the trim edge and gives the cartouche a place to sit. Bleed extends the background past the trim; the map itself is drawn into the bleed too, so nothing shows white if the cut wanders.

Cargo

Terrain

No terrain loaded. Contours draw as vector and export cleanly; the DEM becomes a hillshade underlay.
A DEM comes out of gdal in one line — gdal_translate -of AAIGrid in.tif out.asc — and contours the same way with gdal_contour -a elevation -i 20 in.tif out.geojson. Neither file is stored in the project; they are re-opened when you need them, because a grid is far bigger than everything else put together.

Load from file instead

If the Overpass servers are busy or the extent is large, run the query yourself at overpass-turbo.eu, export the raw JSON, and drop it in here. The plate does not care where the bytes came from.

Place names and sea

OpenStreetMap puts land on the left of a coastline way, and VEDUTA closes the water accordingly. Where a mapper has drawn one backwards, this switch fixes the plate without editing the data.

Press

One ink at a time. A separation is just the plate with everything but one colour taken away, which needs no geometry at all — the kernel is here for the cut plate, where a stroke has to become an outline something can follow.

Draw a proof first.
Each separation is drawn on the paper colour, not the plate background, so a screen printer sees what the squeegee will lay down.

Cut plate

Every stroke becomes a closed outline and the whole lot is unioned, so a junction is cut once rather than three times. This is the slow operation on the bench and it is only ever run when you ask.

Vector

One path per stroke class, coordinates in millimetres with a real physical width and height on the root element, so it drops into a page layout at true size.

PDF for the printer

Written directly, no library. Colour goes out as DeviceCMYK using the same separation the ink report measures, so what you were shown is what gets imaged. Page carries MediaBox, TrimBox and BleedBox; text is Times-Roman in WinAnsi.
